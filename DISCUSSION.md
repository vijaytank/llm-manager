# GitHub Discussions Guidelines

Welcome to the **LLM Manager Discussions**! This is the place to ask questions, share custom templates, suggest integrations, and collaborate on optimizing local LLM server configurations.

---

## 💬 Discussion Categories

When posting in Discussions, please select the most appropriate category:

* **🙋 Q&A & Support**: Need help setting up paths? Having problems connecting VSCode or Claude Code? Post your questions here.
* **💡 Ideas & Feedback**: Got a feature suggestion or an optimization heuristic suggestion? Share it here.
* **🔌 Custom Integrations**: Built a new PowerShell launcher or task template for a client like Continue, LlamaIndex, or LangChain? Post your code snippets and configurations here to help the community!
* **🚀 Show and Tell**: Show off your hardware setup, optimization statistics, or local developer rigs.

---

## 📜 Community Etiquette

* **Search Before Posting**: Your question might have already been answered! Do a quick search of the Q&A category first.
* **Keep it Friendly**: Treat other community members with respect and kindness.
* **Expose No Secrets**: When sharing code snippets, logs, or screenshots, double-check that you are **not** exposing private API keys or folders with sensitive personal names.
