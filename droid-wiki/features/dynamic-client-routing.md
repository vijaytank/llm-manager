# Dynamic Client Routing

**Active contributors:** vijay

Multi-model hosting, automatic client configuration, and seamless integration with development tools.

## Overview

LLM Manager generates a `models-preset.ini` consumed by `llama-server --models-preset`, enabling multi-model hosting with automatic client routing via environment variables and IDE integration.

## Models preset format

```ini
; models-preset.ini (generated at each server start)
[model-alias]
model = /absolute/path/to/model.gguf
alias = model-alias
chat_template = /absolute/path/to/template.jinja
n_gpu_layers = -1
ctx_size = 32768
ubatch_size = 512
cache_type_k = q8_0
cache_type_v = q8_0
flash_attn = on
parallel = 1
spec_type = ngram-simple
context_shift = true
cache_reuse = 256
mmap = 1
```

**Consumed by:** `llama-server --models-preset models-preset.ini`

Clients request models by alias: `curl -H "Authorization: Bearer local" http://127.0.0.1:8080/v1/chat/completions -d '{"model":"model-alias",...}'`

## Port collision protection

```powershell
# In start-server.ps1
$properties = [System.Net.NetworkInformation.IPGlobalProperties]::GetIPGlobalProperties()
$listeners = $properties.GetActiveTcpListeners()

while ($listeners | Where-Object { $_.Port -eq $Port }) {
    $Port++
    $listeners = $properties.GetActiveTcpListeners()
}
```

- Scans active TCP listeners via .NET `IPGlobalProperties`
- Increments port until free socket found
- All exported client env vars updated to resolved port

## Client environment variables

Exported by `start-server.ps1` and provisioned to IDEs:

| Variable | Value | Purpose |
|----------|-------|---------|
| `ANTHROPIC_BASE_URL` | `http://127.0.0.1:<port>` | Routes Anthropic SDK to local server |
| `ANTHROPIC_AUTH_TOKEN` | `local` | Bypasses auth (llama-server accepts any) |
| `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` | `1` | Disables remote telemetry/routing |
| `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY` | `1` | Enables model discovery via gateway |

## Claude Code integration

### Configuration
```json
"integrations": ["claude-code"]
```

### Effects
- `parallel` floored at 2 (prevents subagent deadlocks)
- `idle_timeout_sec` floored at 600 seconds (10 min)
- Wizard offers interactive launch at end of setup

### Tauri launch command
```rust
#[tauri::command]
pub fn launch_claude_terminal(port: Option<u16>, model: Option<String>) {
    // Checks context_manager.enabled in config
    // If enabled: uses proxy_port (8090), else server port
    let script = format!(
        "$env:ANTHROPIC_BASE_URL='{}'; $env:ANTHROPIC_AUTH_TOKEN='local'; $env:CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC='1'; $env:CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY='1'; claude --model $env:_LLO_MODEL",
        base_url
    );
    // Spawns terminal with env vars
}
```

### Manual launch
```bash
ANTHROPIC_BASE_URL=http://127.0.0.1:8080 \
ANTHROPIC_AUTH_TOKEN=local \
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 \
CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1 \
claude --model local
```

## Fallback routing

When no local GGUF models found (`$models.Count -eq 0`):

```json
"fallback_provider": "anthropic",
"fallback_api_key": "sk-...",
"fallback_endpoint": "https://api.anthropic.com",
"fallback_model": "claude-3-5-sonnet-20241022"
```

**Behavior:**
- Skips `llama-server` launch entirely
- Exports client env vars pointing to cloud provider
- Supported: `anthropic`, `openai`, `nim` (NVIDIA), `ollama`

## Bootstrap model

When no models + no fallback:
- Downloads `Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF` from Hugging Face
- Launches via `llama-server -hf Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF`
- Lightweight fallback for immediate usability
