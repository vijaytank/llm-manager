# Applications

**Active contributors:** Vijay

## Purpose

This section documents the three deployable runtime units of LLM Manager: the PowerShell CLI, the Tauri Desktop App, and the Context Manager Proxy. Each page gives a directory layout, key abstractions, how-it-works flow, integration points, entry points for modification, and a key source files table.

## Directory layout

```
droid-wiki/applications/
├── index.md                 # This page — index of the three deployable units
├── tauri-desktop-app.md     # Tauri Desktop App (React + Rust GUI)
├── powershell-cli.md        # PowerShell CLI (wizard + server lifecycle)
└── context-manager-proxy.md # Context Manager Proxy (Python FastAPI service)
```

## Key abstractions

| Abstraction | Description |
|-------------|-------------|
| **PowerShell CLI** | Console entry point (`main.ps1`, `script/*.ps1`, `llo-core/*.ps1`) for wizard, server lifecycle, health checks, and flag verification |
| **Tauri Desktop App** | Native GUI (`ui/src/` + `ui/src-tauri/src/`) that dispatches PowerShell scripts via Rust Tauri commands |
| **Context Manager Proxy** | Optional Python FastAPI service (`llo-core/context_manager/`) translating Anthropic ↔ OpenAI with session compression |
| **Hardware profile** | `SystemHardwareProfile` derived by `llo-core/Profile.ps1`, driving parameter derivation |
| **models-preset.ini** | Generated by `llo-core/SetupRouter.ps1`, consumed by `llama-server` via `--models-preset` |

## How it works

```mermaid
graph TD
    subgraph UI[Tauri Desktop App]
        UI[React frontend + Rust commands] -->|run_powershell_script| PS[PowerShell scripts]
    end
    subgraph CLI[PowerShell CLI]
        Wizard[main.ps1 wizard] --> Config[Write llo-config.json]
        Start[script/start-server.ps1] --> Router[llo-core/SetupRouter.ps1]
        Router --> Preset[Write models-preset.ini]
        Preset --> Server[Launch llama-server]
    end
    subgraph CM[Context Manager Proxy]
        Proxy[proxy.py] --> Engine[context_engine.py]
        Engine -->|Read ctx_limit| Preset
    end
    UI -->|Tauri commands| CLI
    CM -->|Forward to llama-server| Server
    Server --> Clients[Clients: Claude Code, Cursor, Continue, VSCode]
```
